# ERP

Enterprise Resource Planning (ERP) application with Next.js frontend and Express TypeScript backend.

## Project Structure

- `frontend/` - Next.js web application with Tailwind CSS and Shadcn UI
- `backend/` - Node.js Express server with TypeScript and Nodemon

## Quick Start

### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```
Runs at `http://localhost:3000`

### 2. Backend
```bash
cd backend
npm install
npm run dev
```
Runs at `http://localhost:5000`
